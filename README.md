# Gurita Market — Ekstensi Browser

Ekstensi resmi **Gurita Market** untuk riset produk Shopee, Tokopedia & Lazada:
estimasi omzet & terjual, simpan produk dan ulasan ke menu **Riset & Scrape**
di dashboard [app.gurita.market](https://app.gurita.market).

Repo ini hanya berisi **file rilis**. Unduh versi terbaru:

### ⬇️ [Unduh gurita-market-extension.zip](https://github.com/yandyrohman/guritamarket-ext-release/releases/latest/download/gurita-market-extension.zip)

## Cara pasang (Chrome / Edge / Brave)

1. Unduh file **gurita-market-extension.zip** di atas.
2. **Ekstrak** zip-nya (klik kanan → *Extract All* / *Ekstrak Semua*). Akan muncul folder
   `gurita-market-extension`. Simpan folder ini di tempat tetap — jangan dihapus,
   karena browser memuat ekstensi dari folder ini.
3. Buka `chrome://extensions` (Edge: `edge://extensions`).
4. Nyalakan **Developer mode** (pojok kanan atas).
5. Klik **Load unpacked** lalu pilih folder `gurita-market-extension`.
6. Selesai. Sematkan ikon Gurita Market di toolbar, lalu buka
   [app.gurita.market](https://app.gurita.market) dan login — ekstensi ikut login otomatis.

> Kalau sebelumnya memasang versi Chrome Web Store, matikan/hapus dulu agar tidak dobel.

## Cara update ke versi baru

1. Unduh zip versi terbaru, ekstrak.
2. Ganti isi folder `gurita-market-extension` yang lama dengan isi yang baru
   (folder & lokasinya sama).
3. Buka `chrome://extensions` → klik ikon **reload ↻** di kartu Gurita Market.

Daftar perubahan tiap versi ada di halaman [Releases](https://github.com/yandyrohman/guritamarket-ext-release/releases).
